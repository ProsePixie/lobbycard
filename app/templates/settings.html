Point the app at your media folders, add your TMDB key, and make it look the way you like. Nothing is moved, renamed or deleted by this page.

Jump to: Folders · TMDB key · Appearance

Library folder

The folder your shows and movies already live in (or will be filed into), for example Series/Show Name/Season 01.

Incoming folders (optional)

Where finished downloads land before they are filed. You can add more than one, or skip this.

    TMDB API key

    Posters, cast and episode data come from The Movie Database. A free account gets you a v3 API key (32 characters). It is stored only in this app's data folder.

    This product uses the TMDB API but is not endorsed or certified by TMDB.

    Look inside, then save

    A dry run reads file names only and reports what the scanner would make of them. Saving folders restarts the app (if you started it with python run.py).

    Appearance

    Change the title, the subtitle and the header image. These apply the next time the library page loads, no restart needed.

    Preview. The image is cropped to a wide strip; use the slider to choose which part of a tall image stays in view.
    A wide picture works best, around 1600 by 370 pixels. JPEG, PNG, WebP or GIF, up to 8 MB.
