# VORTEX (optional, Windows)

A small launch-pad window for the app and the folders around it: one shortcut instead of several.

![VORTEX](../../docs/screenshots/vortex.png)

| Control | What it does |
| --- | --- |
| the portal | starts the app if it isn't running (`python run.py`, no console window) and opens it in your browser |
| **Downloads** | opens your incoming folder |
| **Pending Deletion** | opens the folder `Purge` moves watched things into (nothing is deleted until you say so) |
| **Empty to Recycle Bin** | sends that folder's contents to the Recycle Bin (undoable from there), after a confirmation |
| **Rename** | runs `pipeline/rename_queue_inplace.py`: applies the TMDB-verified naming to files still in the incoming folder, in place. Anything ambiguous (a reboot, a near-tied title) comes back as a picker instead of a guess |
| **File** | runs `pipeline/file_queue.py`: plans the move into the library, shows a picker with what will happen and why anything is skipped, and files only what you select. Refreshes stale library data first when it needs to |
| status line | whether the app is up, how many shows have missing episodes, how many items sit in Pending Deletion |

It talks to the app only through the same scripts and files the app itself uses (`pipeline/*.py`,
`generated/file_queue_plan.json`, `data/system_status.json`), so it works whether or not the server is running.

## Build and run

Windows only; no SDK needed (it uses the compiler that ships with Windows).

```powershell
powershell -ExecutionPolicy Bypass -File extras\vortex\build_vortex.ps1
extras\vortex\Vortex.exe
```

Run the build from PowerShell, not Git Bash: Bash rewrites the compiler's `/flag` arguments.

## Settings

Optional `vortex.json` next to the exe or in the project root (see `vortex.json.example`):

| Key | Default |
| --- | --- |
| `app_name` | `Entertainment and Talk Over It` |
| `app_port` | `5183` |
| `python_exe` | `.venv\Scripts\python.exe` if present, else the first real `python` on `PATH` |
| `downloads_dir` | the first incoming folder in the app's `config.json`, else your Downloads folder |

`Assets/` (background, portal art, icon) is generated by `tools/make_art.py`; replace the files to restyle it.
`Ctrl+Shift+V` fires a warp burst. `F11` toggles fullscreen.

The built `.exe` is git-ignored; it is always built from `Vortex.cs`.
